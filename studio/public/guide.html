Make a map pack

TOME, the Offline Map Engine, is an interactive map app that works with no connection. It's made for games, and for anything else worth mapping and checking off: the pizza places locals swear by, a scavenger hunt across town, a trail. A pack is a set of maps plus the things on them (benches, chests, clues, restaurants…), which people can filter and check off. TOME Studio is where you make one. Everything happens in your browser: nothing is uploaded.

Quick start: your first pack in 10 minutes

  1. Add a map. In the Maps tab, click Add map from image and pick a picture of the map: a game's world map, a park, a city. Use the biggest, cleanest one you have: people zoom right in.
  2. Make marker types. In Types, add a group (e.g. "Collectibles") and a few types (e.g. "Chest"), each with a colour and icon.
  3. Place markers. In Markers, click Add marker, then click the map. Give it a name, a type and a note. Drag markers to move them.
  4. Name your pack. In Pack, set a name and an id like yourname.gamename.
  5. Download it. In Export, click Download pack (.zip). Then follow Export and publish to get it onto your phone.

Your work is saved in this browser as you go. Map images aren't (they're too big), so after closing the tab you may need to re-add them. Export often: the zip is your real save file.

Marker types

Types are what players filter by and check off. Put them in groups, which become headings in the app's filter panel (Collectibles, Navigation, Bosses…).

  • Pick a colour and an icon so types are easy to tell apart at a glance.
  • Want the game's own icon? Upload icon image takes a small picture (a PNG with a see-through background works best). It's drawn inside the type's coloured circle, in the studio and in the app.
  • Add a wiki page if your pack has a wiki base URL (set in Pack), and the app links to it.

Markers

  • Add marker, then click the map. Drag a marker to move it; click it to edit.
  • Notes are shown offline in the app: how to reach it, what it needs.
  • Untick Can be checked off for things that aren't collected, like benches or shops.

Regions

Regions name parts of a map. They show in the app's info info sheet and in search.

  • Add area (point): a name at one spot, e.g. a town.
  • Draw outline: click around an area, then Finish. An outline can open another map when tapped (e.g. a region on a world map opening that region's detailed map).

Maps

A pack can have several maps: a world overview, a detailed map, an underground layer… Each has its own markers and regions. The first map is the one the app opens on.

  • Click the round button next to a map to show it and edit its markers.
  • Set start view uses what's on screen as where the map opens.

Building a map from pieces

Sometimes a game's map comes as separate pictures, say one per region. The Pieces tab places them on one canvas so neighbours line up, and you can keep adding regions as you go.

  1. Start. Either Maps → Map from pieces (pick all the images), or open an existing map and click Compose this map from pieces: its current image becomes the first piece, locked, so nothing already placed moves.
  2. Line them up. Drag pieces on the map. For fine moves, click a piece and use the ← → ↑ ↓ keys (hold Shift for 10px). Scale fixes a piece captured at a different size.
  3. Use a guide (optional). Add reference image lays a picture, such as a full community map, over the top, see-through. Line pieces up against it. It's never exported, so you can use a picture you aren't allowed to publish.
  4. Lock and link. Tick Locked once a piece is right, so it can't be nudged by accident. Link with joins pieces that already line up, so they move as one bigger piece.
  5. Make room. If a piece goes past the canvas edge (red outline), click Fit canvas to pieces. Markers shift along so they stay on the art.

Markers sitting on a piece move with it when you drag it. Untick Markers and areas move with the piece they're on if you'd rather they stayed.

Zooming between maps

An overview can hand over to a more detailed map: when a player zooms in past the overview's sharpest level, the app switches to the detailed map at the same spot. Zooming back out returns to the overview by itself. You set this up on the overview.

  1. Show the overview, open the Zoom tab, and choose the detailed map under Continue on.
  2. Add matching points: click Add matching point, click a spot you can recognise on the overview (a region's name, a landmark), and the studio switches to the detailed map: click the same spot there. Add 4 or more, spread across the map.
    Shortcut: Match regions by name pairs every region that has the same name on both maps.
  3. Check it with Try it: click anywhere and you jump to where the app would land (a ring marks the spot). Click again to zoom back out. Drag the numbered circles on either map to fix any that are off.
  4. Detailed map not finished yet? Tick the regions it already covers. Zooming in anywhere else stays on the overview, so players never see empty space.

Export and publish

The Export tab lists anything that needs fixing first, then Download pack (.zip) builds the map tiles (big maps take a minute) and saves a zip with:

  • pack.json (the pack), markers/ (the markers), out/ (the map tiles),
  • layout.json and source/ for maps made from pieces,
  • PUBLISHING.md: the steps to share it.

Sharing it

Players add packs in TOME from a GitHub link. In short (PUBLISHING.md in the zip has the exact commands):

  1. Put the folder in a public GitHub repository.
  2. Upload the tile zips from out/ as a release (GitHub keeps big files there).
  3. Players then add it in TOME with yourname/yourrepo/folder.

To publish an update, bump the Version in Pack (e.g. 1.0.0 → 1.1.0) and repeat: players are offered the update.

Editing a published pack

  1. In Pack, either type the link (e.g. yourname/yourrepo/folder) and click Open link, or zip the folder and use Open a pack zip (a whole repo from GitHub's Code → Download ZIP works too).
  2. Map images load from the pack's release by themselves. If one doesn't, use Maps → Load tiles zip with the zip from the release.
  3. Edit, then Export. The zip unpacks to the same folder name: unzip it over your folder, check what changed, and publish as above.

Good to know

Don't change ids after publishing. Players' progress is saved under the pack id and the marker and type ids. Until your first export, ids follow names automatically; after that they're fixed (names can still change).

I reloaded and my map is blank

Images aren't kept in the browser. Published maps reload from their release; otherwise use Add image on the map (or Re-add images… in Pieces, picking all the piece images at once).

How big can a map be?

Most browsers handle images up to about 16,000 pixels across. Bigger is sharper in the app, but slower to export.

Can I use art from the game?

Credit where it came from, and respect the owner's wishes. Fan packs should be free. Use the reference image for anything you're not allowed to share: it stays on your computer.
